# SmartPlacement

SmartPlacement is a placement management web application developed using ASP.NET Core MVC.

## Project Description

This project helps manage college placement activities and provides a platform for students, companies, and placement officers.

## Technologies Used

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- HTML
- CSS
- Bootstrap

## Main Features

- Student management
- Company management
- Job management
- Placement applications
- Placement officer dashboard
- Student and company information management

## Database

The project uses SQLite database with Entity Framework Core.
